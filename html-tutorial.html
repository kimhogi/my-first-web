1. HTML이란?

HTML은 HyperText Markup Language의 줄임말입니다.
웹페이지의 뼈대(구조)를 만드는 언어입니다.

HTML은 태그(tag)로 이루어져 있습니다.

태그 생김새: <태그이름> 내용 </태그이름>

💡 핵심 개념: HTML = 웹페이지의 뼈대 / CSS = 옷(디자인) / JavaScript = 움직임(기능)

2. HTML 기본 구조

모든 HTML 파일은 아래 구조로 시작합니다:

<!DOCTYPE html>          ← HTML5 문서임을 선언
<html lang="ko">         ← HTML 문서 시작 (언어: 한국어)
  <head>                 ← 눈에 보이지 않는 설정 영역
    <meta charset="UTF-8">  ← 한글이 깨지지 않게 설정
    <title>페이지 제목</title>  ← 브라우저 탭에 표시되는 제목
  </head>
  <body>                 ← 실제로 화면에 보이는 내용
    <h1>안녕하세요!</h1>
    <p>여기에 내용을 씁니다.</p>
  </body>
</html>                  ← HTML 문서 끝
주요 구조 태그 설명
태그역할
<!DOCTYPE html>이 파일이 HTML5임을 브라우저에 알림
<html>HTML 문서의 시작과 끝
<head>화면에 보이지 않는 설정 (제목, 인코딩 등)
<body>화면에 실제로 표시되는 모든 내용

3. 제목 태그 <h1> ~ <h6>

h는 Heading(제목)의 줄임말입니다. 숫자가 클수록 작아집니다.

h1 - 가장 큰 제목 (페이지당 1개 권장)

h2 - 큰 제목

h3 - 중간 제목

h4 - 소제목

h5 - 더 작은 제목
h6 - 가장 작은 제목
<h1>가장 큰 제목</h1>
<h2>큰 제목</h2>
<h3>중간 제목</h3>

4. 단락과 텍스트 꾸미기

단락 <p>

p는 Paragraph(단락)의 줄임말입니다.

이렇게 각 문단을 p 태그로 감쌉니다. 새로운 p 태그는 자동으로 줄바꿈됩니다.

줄바꿈 <br>

첫 번째 줄입니다.
br 태그로 줄을 바꿨습니다.
br은 닫는 태그가 없습니다.

텍스트 강조

strong - 굵게 (중요한 내용)

em - 기울임 (강조)

u - 밑줄

s - 취소선

일반 텍스트 중 mark - 형광펜 강조 사용 가능

물의 화학식은 H2O 입니다. (sub - 아래첨자)

넓이는 10m2 입니다. (sup - 위첨자)

<strong>굵게</strong>
<em>기울임</em>
<u>밑줄</u>
<mark>형광펜</mark>

5. 링크 <a>

a는 Anchor(닻)의 줄임말입니다. 다른 페이지로 이동할 때 사용합니다.

외부 링크: 구글 바로가기

같은 페이지 내 이동: 맨 아래 정리로 이동

이메일 링크: 이메일 보내기

<!-- 외부 페이지로 이동 (새 탭에서 열기) -->
<a href="https://www.google.com" target="_blank">구글</a>

<!-- 같은 페이지 내 특정 위치로 이동 -->
<a href="#section-id">해당 섹션으로 이동</a>

<!-- 이메일 링크 -->
<a href="mailto:email@example.com">이메일 보내기</a>
💡 target="_blank" 를 추가하면 새 탭에서 링크가 열립니다.

6. 이미지 <img>

img 태그는 닫는 태그가 없습니다.

<img src="이미지경로.jpg" alt="이미지 설명" width="300" height="200">

<!-- 웹 주소의 이미지 -->
<img src="https://example.com/photo.jpg" alt="사진">

<!-- 같은 폴더의 이미지 -->
<img src="my-photo.jpg" alt="내 사진">
img 태그 주요 속성
속성설명예시
src이미지 주소 (필수)src="photo.jpg"
alt이미지 설명 (이미지가 안 보일 때 표시)alt="내 사진"
width가로 크기width="300"
height세로 크기height="200"

7. 목록 (List)

순서 없는 목록 <ul>

ul = Unordered List

  • 사과
  • 바나나
  • 오렌지

순서 있는 목록 <ol>

ol = Ordered List

  1. HTML 배우기
  2. CSS 배우기
  3. JavaScript 배우기

중첩 목록 (목록 안에 목록)

  • 과일
    • 사과
    • 바나나
  • 채소
    • 당근
    • 브로콜리
<!-- 순서 없는 목록 -->
<ul>
  <li>항목 1</li>
  <li>항목 2</li>
</ul>

<!-- 순서 있는 목록 -->
<ol>
  <li>첫 번째</li>
  <li>두 번째</li>
</ol>

8. 표 (Table)

학생 성적표 예시
이름국어수학영어
김철수859078
이영희928895
박민준768288
 
<table border="1">
  <caption>표 제목</caption>
  <thead>               ← 표 머리 (제목 행)
    <tr>               ← tr = 행(가로줄)
      <th>이름</th>    ← th = 제목 칸 (굵게 표시)
      <th>점수</th>
    </tr>
  </thead>
  <tbody>               ← 표 본문
    <tr>
      <td>김철수</td>  ← td = 일반 칸
      <td>85</td>
    </tr>
  </tbody>
</table>

9. 입력 폼 (Form)

사용자에게 정보를 입력받을 때 사용합니다.



<form>
  <!-- 텍스트 입력 -->
  <input type="text" placeholder="텍스트 입력">

  <!-- 이메일 입력 -->
  <input type="email">

  <!-- 라디오 버튼 (하나만 선택) -->
  <input type="radio" name="같은이름">

  <!-- 체크박스 (여러 개 선택) -->
  <input type="checkbox">

  <!-- 드롭다운 선택 -->
  <select>
    <option>선택지 1</option>
  </select>

  <!-- 여러 줄 텍스트 -->
  <textarea rows="4"></textarea>

  <!-- 버튼 -->
  <button type="submit">제출</button>
</form>
